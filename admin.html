配信投票・クイズシステム 使い方詳細ガイド

手順 配信開始から終了までの基本ステップ

  1. adminアカウントを登録・復元する：ヘッダーの「アカウント登録・復元」から8桁英字の adminId を作成（またはアカウント名とメモから復元）します。
  2. 配信ルーム・配信名を決める：上部の「配信（room）ID」バーで ID生成 を押すか、任意のID・配信名を入力して 配信切替 / 配信名保存 を押します（※ admin が default の場合は room は default 固定）。
  3. URLを配置・配布する：「OBS用URLをコピー」でOBSブラウザソースに設定し、「回答者用URLをコピー」で視聴者に共有します。
  4. 質問を選ぶ：左「1. 出題・受付ステータス操作」で質問を選び、出題切替 を押します。
  5. 投票・回答を受け付ける：投票受付中（またはタイマー付き開始）で受付を開きます。
  6. 締切・結果/正解発表：投票受付終了 後、アンケート結果表示 や クイズ正解表示 に切り替えます。

ルーム切替 配信（room）ID・配信名バーのボタン・表示解説

要素・ボタン 機能と表示の見方
ID生成 重複しにくい 8桁の数字（10000000〜99999999）をランダム生成し、即座にそのルームへ切り替えます。
配信切替 入力欄の文字列（英数字・_・@・-）を正規化してルームを切り替えます。
配信名保存 現在選択中の room_id に配信名（room_name）を紐づけてデータベースへ保存します。
default テストや固定枠用の既定ルーム default にワンクリックで戻ります。
履歴ドロップダウン 過去に切り替えたルームを一覧から選択して即座に切り替えられます（配信名が紐づいている場合は併記）。

URL仕様 ヘッダーのURLコピーボタンとパラメータ

  • OBS用URLをコピー：現在の room / admin が付与された obs.html のURLをクリップボードへコピーします。
  • 回答者用URLをコピー：現在の room / admin が付与された index.html のURLをクリップボードへコピーします。
  • room と admin の違い：room は配信ごとの状態・票・ログを分離し、admin は質問リストを共有管理します（admin が default の時は room も default 固定）。

アカウント adminアカウント登録・復元モーダルの使い方

  • 新規アカウント登録：8桁のランダム英字 adminId を自動生成して登録し、即座にその admin に切り替えます。
  • IDを忘れた時の復元：登録時の「アカウント名」と「メモ」の2つを入力して「アカウント名とメモから特定」を押すことで、該当する adminId を特定・呼び戻せます。
  • default アカウントの制限：admin が default の場合、room は default 固定となり、default 所属の質問は編集・削除・新規作成がロックされます。

進行 出題切替・ステータスボタン・タイマー

  • 出題切替：ドロップダウンで選んだ質問IDを現在の出題対象として反映します（選んだ質問がクイズかアンケートかに応じてステータスボタン群も自動切替）。
  • タイマー付きで投票/回答開始：横の秒数（15秒 / 30秒 / 45秒 / 60秒）を指定して受付を開始します。カウントダウンが0になると自動で CLOSED（受付終了）になります。
  • 現在選択中のボタン枠：現在の配信ステータスと一致するボタンには白い枠線と水色の光彩が付きます。
ステータス OBS（配信画面）の表示 回答者画面（スマホ/PC）の表示
非表示（待機） オーバーレイを非表示にします。 待機中メッセージを表示し、投票操作はロックされます。
投票/回答受付中 質問文と選択肢を表示します（タイマー設定時は残り秒数も連動）。 選択肢ボタンが押せる状態になります。
投票/回答受付終了 受付終了状態を表示します。 新規投票を締め切り、結果待ち表示になります。
結果表示 各選択肢の得票数と割合バーを表示します。 集計結果と割合を表示します。
クイズ正解表示 quiz 種別時に表示され、正解の選択肢を強調表示（紙吹雪などの演出）します。 正解発表と集計結果を表示します。

正解演出 クイズ正解表示（ANSWER）時の演出と表示ルール

  • 紙吹雪などの祝賀エフェクト：クイズ正解表示（ANSWER）に切り替わると、正解発表に合わせた紙吹雪などの演出が動き、クイズの盛り上がりや正解の達成感を視覚的にわかりやすく伝えます。
  • 正解選択肢の強調表示：quiz 種別の質問で設定した正解選択肢が強調表示され、視聴者・回答者に正解が一目でわかるように演出されます。
  • OBS・回答者画面の連動：クイズ正解表示 に切り替えると、OBSオーバーレイと回答者画面（index.html）が同時に正解発表状態へ同期します。
  • 集計結果との併用：回答者画面では正解発表とあわせて集計結果も確認でき、配信の流れに合わせて 集計結果表示 → クイズ正解表示 の順で切り替えるのがおすすめです。
  • コンパクト表示時の注意：OBS表示サイズが コンパクト の場合、オーバーレイ側で結果・正解表示や紙吹雪などの演出が省略されるため、正解演出を配信画面に出したいときは 通常サイズ または 拡大表示 を選択してください。

質問編集 セクション3の各ボタン・入力欄の使い方

  • 編集対象：＋ 新しい質問を作成 を選ぶと新規作成モード、既存質問を選ぶと既存データの読み込み・上書きモードになります（admin_id が default のレコードは編集・削除・保存ができません）。
  • 質問ID：任意ID（例: q3）を指定できます。空欄の場合は q_... で自動採番されます。
  • 種別：アンケート（poll） は正解なし、クイズ（quiz） は正解選択肢を指定できます。
  • ＋ 選択肢を追加 / × ボタン：選択肢は常時2つ以上必要です（2つ以下になると × ボタンは無効化されます）。入力欄で Enter キーを押すと新しい選択肢行を追加できます。
  • 質問を保存する / 入力をクリア / 削除：保存は同一 admin の全配信に反映されます。削除時は確認モーダルが表示されます。

  • OBS表示位置（3×3グリッド）：↖ 左上 / ↑ 上部中央 / ↗ 右上 / ◎ 中央 / ↙ 左下 / ↓ 下部中央 / ↘ 右下 の7箇所へ配置できます。
  • OBS表示サイズ：コンパクト / 通常サイズ / 拡大表示 から選べます。画面の余白や文字の読みやすさに合わせて調整してください。
OBSブラウザソースの推奨設定：幅 1920 × 高さ 1080 で作成すると、3×3のどの位置を選んでも配信キャンバス基準で狙った場所に配置しやすくなります。

ヘッダ画像 回答者画面（index.html）ヘッダ画像の設定

  • ヘッダ反映：「2. OBS表示設定」下部の「回答者画面（index.html）ヘッダ画像URL」に入力した画像URL（横長バナー推奨・推奨サイズ 1000×136px 枠にフィット）を保存し、回答者画面（index.html）の質問カード上部に表示します。
  • 解除：設定中のヘッダ画像を解除して非表示に戻します。

集計ルール リアルタイム集計と重複投票の扱い

  • 同一回答者の再投票：同じ回答者ID（voterId / clientId）が同一質問に複数回投票した場合、集計では最新の1票が反映されます。
  • 現在の配信状態カード：現在のステータスバッジ、残りタイマー、総票数、現在出題中の質問ID・種別・テーマ・位置・サイズを表示します。

ログ・CSV 投票ログ・履歴管理パネルの使い方

  • 質問フィルタ＆検索欄：質問ごとの絞り込みや、回答者ID・選択肢・日時でのキーワード検索が可能です（表示は最大200件まで描画）。
  • 更新ボタン：最新の投票ログをGASから即時取得します。
  • CSV出力：現在フィルタ・検索で絞り込まれているログを、文字化け防止のBOM付きCSV（vote_logs_ルームID.csv）としてダウンロードします。
  • 票をリセット / 選択質問の票をリセット：現在選択中の質問の投票データを削除し、リセット世代番号（resetSeq）を進めて回答者ブラウザの投票済み状態もリセットします。

リセット詳細 リアルタイム集計とログ画面のリセット操作の違い

  • リアルタイム集計の「票をリセット」：現在出題・選択中の質問を対象に、現在の配信ルーム（room）の投票データを削除し、回答者側の投票済み状態もリセットします。
  • ログ画面の「選択質問の票をリセット」：投票ログの質問フィルタで特定の質問を選んでいる場合はその質問を、全質問表示の場合は現在選択中の質問を対象にリセット確認モーダルを開きます。

Q&A よくある症状と確認ポイント

  • OBSや回答者画面に変化が出ない：管理パネル・OBS・回答者それぞれのURLで room と admin が一致しているか確認してください。また、GAS側のコードを更新した場合は「新しいデプロイ」または既存デプロイのバージョン更新が必要です。
  • 投票しようとすると「受付中ではない」と出る：ステータスが 投票/回答受付中 になっているか、タイマーが切れて CLOSED になっていないか確認してください。
  • 質問を保存したのに選択肢が反映されない：選択肢は2つ以上入力されているか確認してください。空白のみの行は除外されます。
  • 投票ログが表示されない：現在切り替えている room に投票データがあるか確認し、ログカードの 更新 ボタンを押してください。
